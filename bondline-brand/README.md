# Bondline brand kit

**Mark:** a coin split by a line. The top half is what you risk, the peach half is the bond, and the periwinkle line is your limit.

| Use | File |
|---|---|
| HackQuest project logo, X/Telegram avatar (square, safe in circle crops) | `png/logo-square-1024.png` |
| HackQuest cover / banner, video title card | `png/cover-1920x1080.png` |
| Link preview (X, Telegram, Discord) | `png/og-image.png` (1200×630) |
| Site header on light backgrounds | `svg/bondline-wordmark.svg` |
| Site header on dark backgrounds | `svg/bondline-wordmark-white.svg` |
| Mark next to text / small UI | `svg/bondline-glyph.svg`, `svg/bondline-glyph-white.svg` |
| App icon | `svg/bondline-mark.svg` (use `bondline-mark-small.svg` at 32px and below) |
| Next.js App Router files (favicon, icon, apple-icon, opengraph/twitter image) | `nextjs-app/` |

**Colors:** ink `#1F1F1F` · paper `#F7F5F1` · periwinkle `#8E97F2` · periwinkle deep `#5E68DC` (text) · peach `#F2A07B` (bond, payouts)

**Type:** Instrument Serif (wordmark, headlines; "line" in italic) · Geist (text) · Geist Mono (numbers, labels). All OFL.

The wordmark SVGs are outlined, so they render the same everywhere without fonts installed.
